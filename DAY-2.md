## for E-commerce website 
⚪Compute: EC2 hosts the web application.
⚪Storage: S3 stores product images and invoices.
⚪Database: RDS stores customer and order information.
⚪Networking: VPC secures the network, Route 53 routes traffic, and CloudFront speeds up content delivery.
⚪Security: IAM controls user permissions, WAF blocks web attacks, Shield protects against DDoS attacks, and KMS encrypts sensitive data.
